# TIPE – Compression de données

Aujourd'hui on assiste à une explosion des données numériques. Tous les jours, des millards de vidéos, messages et photos sont publiés sur internet. Les plateformes comme TikTok, Youtube ou instagram génèrent donc des volumes de données importants.

Or, le stockage de ces données ne sont pas illimlités, car les serveurs ont une capacité limitée, de plus le coût énergétique et économique de l'hébergment et du transfert de données n'est pas négligeable. Par exemple une minute de vidéo de moyenne qualitée non compressée représente plusieurs centaine de mégaoctets.

Pour répondre a ce problème les systèmes informatiques utilisent des algorithmes de compression.

# La problèmatique de ce TIPE est :

**Comment réduire la taille des données tout en conservant l'information qu'elles contiennent ?**

# Lien avec le thème ;

* **sobriété**, car la compression réduit la quantité de données stockées et échangées ;
* **efficacité**, car les fichiers plus petits sont transmis plus rapidement ;
* **optimisation**, car on cherche des algorithmes permettant de représenter l’information de la manière la plus compacte possible.
